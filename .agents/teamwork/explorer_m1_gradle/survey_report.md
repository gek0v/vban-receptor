## 3. Configuration Analysis & Architectural Decisions

### 3.1. Compose Compiler in Kotlin 2.0+
Starting with Kotlin 2.0.0, the Compose compiler has been merged into the Kotlin compiler repository.
- **Rule**: Do **NOT** use `composeOptions { kotlinCompilerExtensionVersion = "..." }`. It is deprecated and produces build warnings/errors in Kotlin 2.0+.
- **Mechanism**: Apply the official Gradle plugin `org.jetbrains.kotlin.plugin.compose` in root `build.gradle.kts` (with `apply false`) and in `app/build.gradle.kts`. Enable Compose in the Android extension via `android { buildFeatures { compose = true } }`.

### 3.2. Native C++ & Prefab Integration
- **Prefab Flag**: `android { buildFeatures { prefab = true } }` instructs AGP to unpack C++ header and CMake configuration files bundled in `com.google.oboe:oboe:1.9.0`.
- **C++ Standard**: C++20 standard specified via `cppFlags("-std=c++20")` in `defaultConfig.externalNativeBuild.cmake`.
- **C++ Standard Library (STL)**: Oboe Prefab AAR is compiled against LLVM `c++_shared`. Specifying `-DANDROID_STL=c++_shared` in `defaultConfig.externalNativeBuild.cmake.arguments` is mandatory to avoid duplicate STL definitions and runtime crashes.
- **ABIs**: `abiFilters("arm64-v8a", "x86_64")` ensures coverage of modern 64-bit physical devices (ARM64) and standard Android x86_64 emulator configurations.
- **CMake Version & Script**: `android.externalNativeBuild.cmake { path = file("src/main/cpp/CMakeLists.txt"); version = "3.22.1" }`.

### 3.3. SDK & API Levels
- `compileSdk = 34`: Required for Android 14 USB DAC mixer bypass API (`AudioMixerAttributes.MIXER_BEHAVIOR_BIT_PERFECT`).
- `minSdk = 26`: Required for Oboe AAudio low-latency audio support (Android 8.0 Oreo).
- `targetSdk = 34`: Targets Android 14.

### 3.4. Local Environment Properties
Because system environment variables `ANDROID_HOME` or `ANDROID_SDK_ROOT` are not defined globally on this machine, `local.properties` is critical:
```properties
sdk.dir=D\:\\Android\\sdk
ndk.dir=D\:\\Android\\sdk\\ndk\\26.1.10909125
```
Both escaped backslashes (`D\:\\Android\\sdk`) and forward slashes (`D:/Android/sdk`) are standard Java property syntax; escaped backslashes are generated by Android Studio and fully recognized by AGP.
